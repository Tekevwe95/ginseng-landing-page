# Ginseng Plus Landing Page

Responsive product landing page starter built with HTML, CSS and JavaScript.

## Structure

- `index.html` — main landing page
- `css/style.css` — design and responsive styles
- `js/script.js` — countdown and demo order form
- `images/` — product and marketing images
- `fonts/` — optional local fonts
- `favicon/` — favicon assets

## Before publishing

1. Replace placeholder product images.
2. Replace sample copy with truthful product information.
3. Add real pricing, delivery and refund details.
4. Connect the order form to your backend/payment provider.
5. Test on mobile and desktop.
